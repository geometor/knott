geometor.knott.phigits¶

Collection 4: Algebraic Powers of \(\Phi\), Continued Fractions & Base-\(\Phi\) “Phigits” (KNOTT-4.1 – KNOTT-4.3).

Catalogs Fibonacci power linearizations, Donald Seitz’s Phibonacci brick, extremal continued fraction convergents \(F_{n+1}/F_n\), Hurwitz’s \(\sqrt{5}\) bound, and George Bergman’s (1957) base-\(\Phi\) (“phigit”) numeral system curated by Dr. Ron Knott on propsOfPhi.html, phigits.html, and cfINTRO.html.

Construct KNOTT-4.1: Geometric area linearization of \(\Phi^2 = \Phi + 1\) and \((\phi + \phi^2)^2 = 1\).

Partitions the \(\Phi \times \Phi\) square AEFD along x = 1 and y = 1 into unit square ABCD (area 1), two golden gnomons BEGC and DCJH (each area \(\phi\)), and corner square CGFJ (area \(\phi^2\)), proving \(\Phi^2 = 1 + 2\phi + \phi^2 = 1 + \phi + 1 = \Phi + 1\), while simultaneously verifying \(\Phi^n = F_n \Phi + F_{n-1}\) for \(n \in [-6, 8]\) and the Phibonacci brick invariants.

Returns:

Verified GeometricCatalogResult for KNOTT-4.1.

Verifies for each \(k = 1\dots \text{count}\) that \(F_{k+1}/F_k - \Phi = (-\phi)^k / F_k\) and \(F_k \phi^k = (1 - (-1)^k \phi^{2k}) / \sqrt{5}\).

geometor.knott.phigits.all_phigit_forms(n: int) → list[str]¶

Enumerate all finite base-\(\Phi\) representations of n not ending in 011.

Implements Dr. Ron Knott’s finite expansion closure (phigits.html#expandall): starting from the minimal representation to_phigits(), applies all sequences of:

  1. Interior 100 -> 011 (\(k \to \{k-1, k-2\}\) for \(k > \min(E)\));

  2. Tail 101 -> 01111 (\(\{m+2, m\} \to \{m+1, m, m-1, m-2\}\) at \(m = \min(E)\)).

For every Fibonacci number \(F_k\) (\(k \ge 2\)), len(all_phigit_forms(F_k)) == F_k.

Parameters:

n – Positive integer (\(n \ge 1\)).

Returns:

Deterministically sorted list of valid finite base-\(\Phi\) strings for n.

geometor.knott.phigits.construct_phigit_scale_model() → geometor.knott.flat_geometry.GeometricCatalogResult¶

Construct KNOTT-4.3: Geometric phigit Decomposition of integers 1..6 over \(\Phi^k\).

Builds an exact geometric bar-and-power decomposition diagram in geometor.model: horizontal reference ticks at powers \(\Phi^{-2} = \phi^2\), \(\Phi^{-1} = \phi\), \(\Phi^0 = 1\), \(\Phi^1 = \Phi\), \(\Phi^2 = \Phi + 1\), and \(\Phi^3 = 2\Phi + 1\), paired with stacked horizontal segments proving \(2 = \Phi^1 + \Phi^{-2}\), \(3 = \Phi^2 + \Phi^{-2}\), and \(4 = \Phi^2 + \Phi^0 + \Phi^{-2}\). Also verifies Bergman uniqueness and Knott’s Fibonacci fixed-point theorem #all_phigit_forms(F_k) == F_k for \(k = 2..8\).

Returns:

Verified GeometricCatalogResult for KNOTT-4.3.
