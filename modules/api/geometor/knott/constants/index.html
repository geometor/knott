geometor.knott.constants¶

Exact symbolic constants, notation bridges, and Rational Trigonometry invariants.

Dr. Ron Knott’s archive (Fibonacci Numbers, the Golden Section and the Golden String, University of Surrey) uses uppercase \(\Phi = (1 + \sqrt{5})/2\) for the Golden Ratio (\(\approx 1.61803\dots\)) and lowercase \(\phi = \Phi - 1 = 1/\Phi = (\sqrt{5} - 1)/2\) for its reciprocal (\(\approx 0.61803\dots\)). By contrast, SymPy and geometor.model denote the larger root by sp.GoldenRatio (\(\phi_{\text{GEOMETOR}} = \Phi_{\text{Knott}}\)).

This module provides exact closed-form \(\mathbb{Q}(\sqrt{5})\) definitions alongside lossless symbolic conversion helpers and Rational Trigonometry invariants.

Galois conjugate \(\Psi = 1 - \Phi = -\phi = (1 - \sqrt{5})/2 \approx -0.6180339887\dots\).

geometor.knott.constants.floor_linear_phi(a: int | sympy.Rational, b: int | sympy.Rational) → int¶

Compute \(\lfloor a + b\Phi \rfloor\) for \(a, b \in \mathbb{Q}\) using pure integer algebra.

Rewrites \(a + b\Phi = (2a + b + b\sqrt{5}) / 2\) over a common positive integer denominator and determines the exact integer floor via integer square roots sp.integer_nthroot with zero floating-point evaluation.

Parameters:

  • a – Rational constant term.

  • b – Rational coefficient of \(\Phi\).

Returns:

Exact Python int equal to \(\lfloor a + b\Phi \rfloor\).
